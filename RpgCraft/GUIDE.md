# RpgCraft 플레이 가이드

레벨을 올리고, 장비를 모으고, 강화하고, 길드를 꾸려 성을 빼앗는 대규모 RPG·PvP 서버입니다.
처음이라면 **1장 → 2장 → 3장**만 읽어도 바로 플레이할 수 있습니다.

---

## 1. 처음 접속하면

1. 접속하면 **전용 리소스팩** 적용 창이 뜹니다. **예**를 눌러주세요. 무기가 3D로 보이고 메뉴가 전용 디자인으로 바뀝니다.
2. 첫 접속 선물로 **몽둥이 · 초보자용 채집도구 · 하급 포션 5개 · 2,000원**을 받습니다.
3. **쉬프트 + F** 를 눌러 메인 메뉴를 열어보세요. 거의 모든 기능이 여기 있습니다.
4. 월드 스폰 근처의 약한 몬스터부터 잡으며 레벨을 올립니다. 스폰에서 멀어질수록 몬스터 레벨이 올라갑니다 (약 40칸마다 +1).

### 조작키

| 키 | 기능 |
|---|---|
| **쉬프트 + F** | 메인 메뉴 (`/메뉴`) |
| **F** | 포션가방의 포션 즉시 사용 |
| **쉬프트 + Q** | 퀵 액티브 스킬 (스킬 메뉴에서 우클릭으로 지정했을 때만, 아니면 평소처럼 아이템 버리기) |
| **우클릭** | 사신수 무기 스킬 사용 / 기운 뽑기 결정 개봉 / 수표·토템 뽑기권·스탯 초기화권 사용 |
| **좌클릭 (공성전)** | 채집도구로 적 성벽 두드리기 |
| **쉬프트 유지 (공성전)** | 성벽 수리 망치를 들고 10초 → 우리 성벽 수리 |

### 나침반 · 알림
- 화면 **위쪽 나침반**이 바라보는 방향의 방위(북·동·남·서)를 보여줍니다. 히든 상인이 나타나면 **✦**, 근처 웨이브 깃발은 **⚑** 로 방향이 표시됩니다.
- 레벨업·쿨타임 같은 알림은 체력바 위에 짧게 나타났다 사라집니다.
- 오른쪽 사이드바는 메뉴 > 설정에서 끄고 켤 수 있습니다.
- **도감**에는 한 번이라도 얻은 아이템만 기록됩니다. 분류마다 발견 수가 표시되니 모아 보세요.

### 화면 보는 법 (리소스팩 적용 시)
바닐라 하트·갑옷·배고픔 대신 **전용 HUD**가 그 자리에 표시됩니다.

```
 ⚔ 1284                          ✦ 32.5%          ← 공격력 / 크리티컬
 ❤[■■■■■■■ 15230/20000 ]        🧪12 ⚡8s 🛡24.5% ← 체력 / 포션 수 / 퀵 스킬 쿨타임 / 방어력
 [══════════ 금색 경험치 바 ══════════]
 [ 핫바 ]
```
- 퀵 스킬이 사용 가능하면 번개 아이콘이 노랗게, 쿨타임 중이면 회색 + 남은 초가 표시됩니다.
- 사이드바 제목과 탭 목록 머리말에 서버 로고가 나오고, 메뉴마다 전용 배경 화면이 적용됩니다.
- 리소스팩을 거절했다면 예전처럼 글자로 된 상태줄이 나옵니다.

### 화면 보는 법 (공통)
- **액션바 (화면 아래)**: 체력 바 · 공격력 · 크리티컬 · 방어력 · 퀵 스킬 쿨타임
- **사이드바 (오른쪽)**: 회차 · 레벨 · 소지금 · 스탯 포인트 · 전투력 · 일일 의뢰 진행도 · 길드
- **몬스터 이름표**: `Lv.35 좀비 ▌▌▌▌▌▌▌▌▌▌` — 맞은 뒤 잠시 체력 바가 보입니다. 레벨 색이 붉을수록 위험합니다.
- 사이드바·액션바·대미지 숫자가 거슬리면 **메뉴 > 설정**에서 끌 수 있습니다.

## 1-1. 무기 스킬 (좌클릭 · 우클릭)

| 무기 | 좌클릭 (평타 3타마다 발동) | 우클릭 (강공격, 쿨타임) |
|---|---|---|
| 검 | 회전 베기 (주변 적) | 검기 — 전방 부채꼴 참격 (6초) |
| 단검 | 연속 찌르기 (추가 2타) | 그림자 습격 — 앞의 적 뒤로 순간이동 후 일격 (7초) |
| 도끼 | 내려찍기 (범위 + 띄우기) | 대지 가르기 — 전방 6칸 연쇄 폭발 (9초) |
| 방패 | 방패 강타 (1초 기절) | 방패 돌진 — 돌진 + 기절 (8초) · 쉬프트+우클릭 = 막기 |
| 활 | **좌클릭 = 즉시 속사** (3발째 부채 사격) | **우클릭 = 폭풍 화살** — 관통 화살 5연사 (6초) |
| 창 · 몽둥이 | 관통 찌르기 / 강타 | 창 투척 / 휩쓸기 |

**무기마다 스킬이 다릅니다.** 같은 검이라도 무기에 따라 우클릭이 관통 일섬일 수도, 소용돌이일 수도 있어요. 아이템 설명의 **"✦ 무기 스킬"** 에서 확인하세요. (위 표는 평타 스킬 기준)
**희귀 등급 이상 무기**는 추가 스킬이 있습니다: **Shift+좌클릭** 돌진 베기(활: 후퇴 사격) · **Shift+우클릭** 충격파(활: 화살비).
**레전드 등급 이상**(사신수·신화 유물)은 **쉬프트를 빠르게 두 번** 누르면 궁극기가 발동합니다(60초). → 최상위 장비는 스킬 5개

- **좌클릭은 참격**입니다. 몬스터를 정확히 맞히지 않고 허공을 휘둘러도 앞쪽 부채꼴(약 3.5칸, 창은 4.5칸 직선) 안의 적을 벱니다. 무기 등급·속성 색의 참격 이펙트가 나옵니다.
- 휘두를 때마다 참격 방향이 번갈아 바뀝니다. 스킬은 위아래 시선과 상관없이 정면으로 나갑니다.
- 활은 당겨서 조준하지 않습니다. 화살도 필요 없습니다.
- 스킬 위력 = 공격력 × 배율 + **마력** × 배율 (힘을 올리면 마력도 오름)
- HUD 의 번개 아이콘이 강공격 쿨타임입니다. 사신수 무기는 전용 우클릭 스킬을 그대로 씁니다.

## 2. 성장: 레벨과 스탯

- 레벨이 오를 때마다 **스탯 포인트 5**와 **최대 체력 +200**을 얻습니다.
- `/스탯` (메뉴 > 스탯)에서 포인트를 나눕니다. 좌클릭 +1, 우클릭 +10, 쉬프트 클릭 = 전부.

| 스탯 | 효과 | 필요한 장비 |
|---|---|---|
| **힘** | 공격력 (2포인트당 +3) · **마력** (1포인트당 +2, 스킬 위력) | 검, 도끼(절반) |
| **민첩** | 치명타 확률 (+0.1%) · **치명타 피해** (+0.5%) · **이동속도** (+0.05%, 최대 30%) | 단검, 도끼(절반) |
| **모험** | 최대 체력 (+40) · **방어력** (+0.05%) | 방패, 유적 입장 조건 |

**50포인트마다 특별 효과**: 힘 50마다 힘 +3%·방어 관통 +2 / 민첩 50마다 치명타 피해 +6%·이동속도 +1% / 모험 50마다 체력 +3%·방어력 +1

- 장비에는 **요구 레벨/스탯**이 있습니다. 조건을 못 채우면 장비 능력치가 적용되지 않고 액션바에 빨간 경고가 뜹니다.
- 스탯을 다시 나누고 싶다면 **스탯 초기화권**(특수 상점)을 우클릭하세요.

## 2-1. 직업

`/직업` 또는 메뉴 > 직업

1. **Lv.10 — 기초 직업 선택**: 전사 / 궁수 / 도적 / 수호자 중 하나를 직접 고릅니다.
2. **Lv.40 — 2차 전직** (50만원): 그때 **가장 많이 투자한 스탯**으로 세부 직업이 정해집니다. 스탯 분배가 곧 나만의 직업!

| 기초 | 힘 위주 | 민첩 위주 | 모험 위주 |
|---|---|---|---|
| 전사 | 버서커 — 강공격 +30%, 흡혈 | 검성 — 평타 스킬 2타마다 | 전장의 군주 — 강공격 후 피해 30% 감소 |
| 궁수 | 저격수 — 활 강공격 +50% | 질풍 궁수 — 스킬 쿨타임 -30% | 레인저 — 강공격 적중 시 둔화 |
| 도적 | 처형자 — 체력 30% 이하 적에게 +50% | 그림자 — 강공격 후 1.5초 무적 | 약탈자 — 처치 시 돈 +30% |
| 수호자 | 성기사 — 강공격 시 체력 10% 회복 | 파수꾼 — 피격 시 20% 반격 | 철옹성 — 받는 피해 10% 반사 |

직업을 바꾸려면 **직업 초기화권**(히든 상인·특수 상점)을 우클릭하세요. 대장장이는 제작 전문 직업으로 따로 전직합니다.

## 3. 전투

- 체력은 수천~수만 단위입니다. 하트는 비율만 보여줍니다.
- **크리티컬**은 대미지 **2배**에 **상대 방어력을 무시**합니다.
- 무기마다 공격 간격이 다릅니다. 너무 빨리 연타하면 대미지가 줄어듭니다.

| 무기 | 간격 | 특징 |
|---|---|---|
| 단검 | 0.3초 | 빠름, 민첩 무기 |
| 몽둥이 | 0.5초 | 초보자용 |
| 검 | 0.6초 | 강한 한 방, 크리티컬 -20% |
| 방패 | 0.7초 | 공격 + 방어력, 막기 시 받는 피해 -30% |
| 창 | 0.8초 | 현무 전용 |
| 도끼 | 0.9초 | 느리지만 묵직함 |
| 활 | 당길수록 강함 | 원거리 공격력 사용 |

- 전투가 끝나고 8초가 지나면 체력이 빠르게 회복됩니다. 급할 땐 **F(포션)**.
- **레벨 10 미만**은 PvP 보호를 받습니다. 같은 길드끼리는 서로 공격할 수 없습니다.
- 죽어도 **아이템은 잃지 않습니다** (서버 설정에 따라 다를 수 있음).

## 4. 장비

### 등급
| 등급 | 표시 | 설명 |
|---|---|---|
| 노말 | ◇ 흰색 | 상점 장비 |
| 레어 | ◆ 초록 | 보스 세트 등 |
| 유니크 | ✦ 노랑 | 대장장이 제작품 |
| 레전드 | ❖ 빨강 | 사신수 장비 |
| 신화 | ✧ 보라 | 월드보스에서만 극히 드물게 나오는 유물 |

바닥에 떨어진 장비는 등급 색으로 빛나고, 유니크 이상은 빛기둥이 섭니다.

### 얻는 곳
- **상점**: `/상점` 또는 NPC. 무기(Lv10~40), 전사/암살자/모험가 방어구, 재료, 포션, 채집도구
- **보스**: 보스 세트 (세트를 여러 부위 입으면 세트 효과)
- **대장장이**: 유니크 장비 제작 (6장)
- **사신수 조합**: 레전드 장비 (8장)
- **신화 유물**: 월드보스 0.5% 드롭
- **도감**(메뉴 > 도감)에서 모든 아이템의 **획득처와 드롭 확률**을 볼 수 있습니다.

## 5. 강화

`/강화` (메뉴 > 강화) 에 장비를 넣고 버튼을 누릅니다.

- 강화할수록 공격력(무기) 또는 방어력·체력(방어구)이 오릅니다. 모든 장비 최대 **+15**
- 필요한 것: **돈** + **재료** (+0~4: 철괴, +5~7: 은괴, +8~10: 금괴, 그 이후: 크리스탈)
- **+5 이상**에서 실패하면 단계가 내려갈 수 있고, **+8 이상**부터는 **파괴** 위험이 있습니다.
- 도움 아이템:
  - **파괴 방지권**: 파괴될 상황을 1회 막아줍니다 (+7 이상에서 사용)
  - **강화 확률 10% 증가권**: 성공 확률 +10%
- **+7 『각인』**: 무기에 룬이 새겨지며 모습이 바뀝니다.
- **+10 『완성』**: 무기 전체가 빛나고, 손에 들면 은은한 빛이 납니다.
- 보스 세트 장비는 강화할 수 없습니다.

## 6. 채집과 대장장이

### 채집
채집도구를 들고 흙·잔디(약초·버섯), 원목(나무), 돌·광석(광물)을 부수면 재료를 얻습니다. 블록은 사라지지 않습니다.

| 채집도구 | 쿨타임 | 성벽 대미지 |
|---|---|---|
| 초보자용 | 3분 | 15 |
| 중급자용 | 2분 | 70 |
| 숙련자용 | 1분 | 100 |

좋은 도구일수록 희귀 재료(백년 산삼, 황금나무, 크리스탈, 희귀 광석)가 잘 나오고, 낮은 확률로 **기운 파편**도 나옵니다.

### 대장장이
- 전직: `/직업 대장장이` (레벨 20, 1,000,000원)
- `/제작` 에서 5단계 유니크 장비를 만듭니다: **무쇠맹세 → 서리벼림 → 장인긍지 → 용광로심장 → 창세불씨**
- 제작할 때 능력치가 75~100% 품질로 정해지고, 추가 옵션이 1줄 붙습니다.
- 직접 만든 장비는 `/명명 <이름>`(색 코드 & 가능), `/외형 <모델번호>` 로 꾸밀 수 있습니다.
- 대장장이는 강화 확률 +5% 보너스를 받습니다.

## 7. 룬과 포션가방

- **룬** (`/룬`): 3칸에 장착. 하급/중급/상급 룬에는 랜덤 능력치 3줄이 붙습니다 (가끔 마이너스 옵션도 있음).
  - 옵션이 마음에 안 들면 룬을 손에 들고 `/룬 변경` (룬 변경권 1장 소모)
- **포션가방** (`/포션가방`): 포션을 보관하고 **F** 키로 즉시 마십니다.
  - 좌클릭으로 F키에 쓸 포션 선택, 우클릭으로 꺼내기
  - 회복량: 하급 500 · 중급 2,000 · 상급 6,000 · 최상급 15,000

## 8. 사신수 · 사흉수 (최상위 장비)

1. **월드보스**(사막의 악몽 → 불, 시포니아 → 바람, 카인 → 어둠)와 **채집**(자연, 땅)에서 **기운 파편**을 모읍니다.
2. `/기운` 에서 파편 **5개** → **기운 뽑기 결정** 1개
3. 결정을 **우클릭** → **30%** 확률로 **기운** 획득
4. 기운으로 조합:

| 결과 | 재료 |
|---|---|
| 청룡의 검 | 바람의 기운 5 + 유니크 검 |
| 백호의 도끼 | 땅의 기운 5 + 유니크 도끼 |
| 주작의 단검 | 불의 기운 5 + 유니크 단검 |
| 현무의 창 | 자연의 기운 5 + 유니크 무기 아무거나 |

- **펫** (`/펫`): 펫 뽑기 → 펫 알 우클릭으로 도감 등록 → 도감에서 하나를 꺼내면 따라다니며 능력치를 올려 줍니다. 전설 펫 1%.
- **탈것** (`/탈것`): 등급이 높을수록 빠르고 높이 뜁니다. 전설 탈것은 점프로 이륙해 바라보는 방향으로 날 수 있습니다 (다시 점프하면 착지).
- **히든 퀘스트**: 맵 먼 곳 어딘가의 "???" NPC. 조건을 채워 찾아가면 서버에 3명만 가질 수 있는 패시브를 줍니다.
- **길라잡이** (`/길라잡이`): 처음 할 일을 순서대로 안내하고 단계마다 보상.
- **쿠폰** (`/쿠폰 <코드>`), **퀵 스킬 키** (`/퀵키 쉬프트Q | 쉬프트9 | 9`), **다른 플레이어 정보**: 쉬프트+우클릭.
- **전당포** (`/상점 pawn`): 어디서도 못 팔던 전리품·재료도 여기서 팝니다.

## 10-14. 3차 전직 (Lv.100)

직업 메뉴 오른쪽 아래 **3차 전직** 버튼을 쉬프트 클릭. 조건: Lv.100, 10,000,000원, 마력 핵 10개. 2차 효과는 그대로 유지되고 더 강한 효과가 붙습니다.

## 13. 공성전

1. 길드장이 **전쟁권**을 들고 `/전쟁 선포 <성ID>` (회차당 1번). `/전쟁 목록` 으로 성 목록 확인.
2. **10분 준비** 후 **20분 전쟁**이 시작되고, 양쪽 길드원이 각 진영으로 이동합니다.
3. 공격측은 **채집도구**로 성벽을 두드려 체력을 깎습니다 (도구가 좋을수록 강함).
4. 성벽 **3개**가 무너지면 **신호기**가 드러납니다. 신호기를 부수면 **승리** — 성 점령 + 상대 금고 30% 약탈 + 보상금.
5. 방어측은 **성벽 수리 망치**를 들고 성벽 근처에서 **쉬프트 10초** → 성벽 회복.
6. 시간이 끝나면 방어측 승리. 전쟁 중에는 상대 길드와 PvP 보호가 사라집니다.

## 15. 서버 운영자 빠른 세팅

1. `RpgCraft.jar` 를 `plugins` 에 넣고 서버 실행 → `plugins/RpgCraft/` 생성
2. **리소스팩 배포** — 서버가 포트 **8765** 로 팩을 직접 배포하고, 플레이어가 접속한 주소를 자동으로 씁니다.
   - 방화벽·공유기(포트포워딩)·호스팅 패널에서 **TCP 8765** 를 열어야 합니다. 다른 PC 브라우저에서 `http://서버주소:8765/RpgCraft.zip` 이 받아지면 정상입니다.
   - `/rpg관리 pack test` 로 서버에서 접속 진단, 플레이어가 받지 못하면 콘솔에 실제 주소와 원인이 표시됩니다.
   - **현재 설정: GitHub 배포** — `resourcepack.url` 에 GitHub 주소가 들어 있어 8765 포트 없이 GitHub 에서 팩을 받습니다.
     GitHub 파일 페이지 주소(`/blob/`)를 넣어도 자동으로 직접 다운로드 주소로 바뀌고, SHA-1 은 서버가 시작할 때 자동 계산합니다.
     **플러그인을 업데이트하면 `dist/RpgCraft-ResourcePack.zip` 을 GitHub 에도 다시 올려주세요.** (다르면 콘솔에 안내가 나옵니다)
   - **포트를 열 수 없는 호스팅**: `dist/RpgCraft-ResourcePack.zip` 을 외부(깃허브 릴리스, mc-packs.net 등 직접 다운로드 링크)에 올리고 `resourcepack.url` 에 주소, `resourcepack.sha1` 에 `/rpg관리 pack status` 의 SHA-1 을 넣으세요.
   - **직접 설치 방식**: 플레이어가 zip 을 `.minecraft/resourcepacks` 에 넣어 켜고, 서버는 `resourcepack.enabled: false`, `resourcepack.assume-installed: true` 로 설정.
   - 커스텀 HUD·메뉴 전용 배경·사이드바 로고·탭 로고는 팩을 받은 플레이어에게 자동으로 적용됩니다.
   - 채팅/탭의 레벨 배지는 다른 사람 화면에도 보이는 글자라 `resourcepack.required: true` 일 때만 켜집니다.
3. 상점 NPC: `/rpg관리 npc general`, `weapon`, `armor_warrior`, `armor_assassin`, `armor_adventurer`, `special`, `wandering`, `war`
4. 워프: 주요 장소에서 `/rpg관리 warp set spawn 스폰 BEACON 1`
5. 성: `castle create` → `pos1`/`pos2` → `castle wall` ×3 → 신호기 설치 후 `castle beacon` → `castle spawn`
6. 보스는 `/rpg관리 boss spawn <id>` (정기 소환은 스케줄러 플러그인 권장)
7. **기존 맵에 적용할 때**: 플러그인은 지형이나 건물을 만들지 않습니다. 아래는 자동/수동이 나뉩니다.

   | 항목 | 기존 맵에 넣으면 |
   |---|---|
   | 몬스터 레벨 | **자동** — 월드 스폰에서 멀수록 강해짐 (네더·엔드는 높은 레벨부터) |
   | 채집 포인트 | **자동** — 맵에 있는 모든 풀·꽃·원목·돌·광석이 채집 포인트 |
   | 야생 방지 · HUD · 메뉴 · 리소스팩 | **자동** |
   | 유적 (점프맵) | **명령어 한 번** — `/rpg관리 structure ruin` (또는 기존 건물에 시작/도착 블록 지정) |
   | 성 (공성전) | **명령어 한 번** — `/rpg관리 structure castle` (성벽 4면·신호기·진영 스폰 자동 등록) |
   | 장식 구조물 | **자동** — 새로 탐험하는 지역에 확률적으로 생성 (`structures.natural-chance`) |
   | 상점 NPC · 워프 | **수동** — 원하는 위치에서 명령어로 배치 |
   | 보스 | **수동** — 명령어로 소환 (정기 소환은 스케줄러 플러그인) |

   건축은 `/gamemode creative` → `/rpg관리 build` 로 건축 모드를 켜고 하세요.
