# RpgCraft 아이템 디자인 시스템 (v1.4.0)

## 0. 3D 모델 (v1.4.0)
- 모든 전용 아이템(100종)은 **입체 모델**로 렌더링됩니다. `tools/voxel3d.py`가 텍스처 픽셀에 두께를 주고 같은 두께끼리 직육면체로 묶어 Minecraft 모델 요소를 만듭니다. 모델당 평균 약 68개 요소, 모두 합쳐 약 6,800개입니다.
- 두께는 디자인 부품별로 다릅니다. 칼날은 날 끝 1.0에서 중앙 능선 1.5로 도톰해지고, 가드는 3.0, 손잡이는 2.0, 보석은 3.5로 가장 튀어나옵니다. 도끼는 날에서 자루 쪽으로 두꺼워지고, 방패는 판 2.0에 테두리·징 3.0, 문장 2.5입니다. 포션·보주·룬·광석은 가장자리에서 멀수록 부풀고, 티켓은 얇은 종이입니다.
- 인벤토리에서는 정면 조명(gui_light: front)이라 기존 아이콘과 같게 보이고, 손에 들거나 바닥에 떨어지거나 액자에 걸면 입체로 보입니다.
- 강화 +7/+10 모델은 같은 입체 형상을 부모로 공유하고 텍스처만 바꿉니다. 그래서 모델 수가 늘어나지 않습니다.
- 텍스처를 직접 그려 윤곽이 바뀌면, 빌드할 때 자동으로 그 PNG의 모양(가장자리 거리)을 기준으로 두께를 다시 계산합니다.
- 옵션: `python3 tools/build_resourcepack.py --flat` → 예전 평면 모델, `python3 tools/preview3d.py 이름 ... -o out.png` → 입체 미리보기


## 1. 분석 요약 (리워크 전)
- 아이템 원형 약 200종 (`ItemRegistry` + 대장장이 `bs_*` 40종), 등급 4단계 `NORMAL/RARE/UNIQUE/LEGEND`
- 장비 스탯은 아이템 PDC에 저장 → 기존 아이템 ID·PDC 구조는 **그대로 유지**
- 모델: CustomModelData 방식, 기존 텍스처는 색만 다른 16x16 도형 → 실루엣 구분이 약함
- 이름은 나무위키 4R 명칭 → **이름은 유지**하고 칭호·세계관 문구로 개성을 부여

## 2. 등급 체계
| 등급 | 색 | 디자인 규칙 | 드롭 연출 | 획득 연출 |
|---|---|---|---|---|
| ◇ 노말 | 흰색 | 단순한 금속·나무·가죽, 장식 최소 | 없음 | 없음 |
| ◆ 레어 | 초록 | 재질 개선, 작은 장식/보석 | 초록 발광 + 이름표 | 효과음 + 액션바 |
| ✦ 유니크 | 노랑 | 보석·룬·독특한 가드 | 노랑 발광 + 빛기둥(3칸) | 금빛 고리 + 부제목 |
| ❖ 레전드 | 빨강 | 전용 실루엣, 강한 색 대비 | 빨강 발광 + 빛기둥(5칸) + 바닥 고리 | 타이틀 + 충격파 + 전체 공지 |
| ✧ 신화 ✧ (신규) | 보라 | 부유하는 결정, 비정상적 실루엣, 에너지 코어 | 보라 발광 + 빛기둥(7칸) + 도는 광점 | 나선 + 구체 + 타이틀 (약 1.2초) |

## 3. 무기 종류별 디자인 언어 (tools/pack_art.py)
무기는 대각선 좌표계 `(s, t)`에서 **칼날 윤곽 함수 · 가드 · 손잡이 · 폼멜 · 장식**을 조립해 그린다. 색이 아니라 윤곽 함수가 달라서 실루엣이 달라진다.

- **검**: 짧고 넓은 검(초보) → 홈 있는 장검 → 이 빠진 전쟁검 → 피홈 대검 + 해골 폼멜(공포장검)
  / 마녀=뱀처럼 굽이치는 칼날, 드워프=상자형 가드의 룬 대검, 하피=휜 세이버 + 깃털 가드, 심해=산호 가시, 붕붕이=불꽃 물결
- **단검**: 기본 → 스틸레토(가늘고 김) → 휜 은장 → 톱니 등날 / 낫형, 삭스, 발톱, 송곳니, 크리스
- **도끼**: 녹슨 손도끼 → 수염 도끼 → 양날 → 황금 초승달 / 가시 초승달, 룬판 양날, 날개, 닻, 불꽃 혀
- **방패**: 원형 목재 → 히터 → 카이트 → 타워 / 오각 눈 문장, 룬 원형, 날개, 가리비, 태양
- **세트 정체성**: 같은 보스 세트는 같은 주색·보조색·보석색을 공유 (예: 마녀 = 보라 + 독 초록)
- **신화 유물**: 여명을 가른 서약(칼날이 세 조각으로 떠 있음) · 심연의 쌍송곳니(평행한 두 칼날) · 일식(가운데가 뚫린 고리 도끼) · 무너지지 않는 맹세(네 조각으로 분리된 방패 + 결정 코어)

## 4. 강화 단계
모델 수를 폭증시키지 않도록 **두 단계만** 추가하고, 텍스처는 같은 디자인에서 자동 파생한다.
| 단계 | 모델 | 연출 |
|---|---|---|
| +0~+6 | 기본 | 로어의 강화 별(★☆) |
| +7 『각인』 | CMD +3000 : 홈·문양이 룬처럼 빛남 | 이름 굵게, 손에 든 무기 주변 은은한 광점 |
| +10 『완성』 | CMD +5000 : 날 전체 발광 + 칼끝 별빛 | 『+10』 표기, 완성 연출, 타격 시 등급색 고리 |
강화 대상: 노말 무기 16, 대장장이 20, 사신수 4, 신화 4 (보스 세트는 강화 불가라 제외). 대장장이 `/외형`으로 바꾼 모델은 덮어쓰지 않는다.

## 6. 신화 유물 특수 효과 (ItemEffectManager)
| 유물 | 효과 | 획득 |
|---|---|---|
| 여명을 가른 서약 (검) | 단죄: 크리티컬 시 공격력 40% 추가 피해 | 카인 0.5% |
| 심연의 쌍송곳니 (단검) | 20% 확률 3초 출혈 | 시포니아 0.5% |
| 일식 (도끼) | 5번째 근접 적중마다 4칸 원형 참격 150% | 사막의 악몽 0.5% |
| 무너지지 않는 맹세 (방패) | 피격 시 15% 확률 피해 반감 + 30% 반사 | 카인 0.5% |

## 7. 성능 원칙
- 무한 반복 작업은 3개뿐: 드롭 연출(0.5초), 손 오라(1초), 기존 HUD — 모두 대상이 있을 때만 파티클 생성
- 드롭 발광/빛기둥은 최대 80개, 반경 40칸 안에 플레이어가 있을 때만, 2분 후 자동 해제
- 획득·강화 연출은 1~2초 안에 끝나는 일회성 태스크
