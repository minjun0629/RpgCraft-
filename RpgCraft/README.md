# RpgCraft

레벨·스탯, 수만 단위 체력 전투, 강화, 보스·월드보스, 채집, 대장장이, 룬, 사신수, 길드·공성전, 유적, 히든 패시브를 담은
**대규모 RPG·PvP 서버 플러그인** (Spigot/Paper 1.20.1, Java 21) + **전용 3D 리소스팩**. 대형 방송 RPG 콘텐츠(마크에이지 4R)의 규칙에서 출발했습니다.

- 게임 방법과 명령어 전체: **`GUIDE.md`**
- 아이템 디자인 설계: `ITEM_DESIGN.md`
- 빌드: `build.bat` / `./build.sh` → `dist/RpgCraft.jar` · 리소스팩: `dist/RpgCraft-ResourcePack.zip`

- **관리자 옥션 관리 명령어 `/rpg관리 auction`**

  - `/rpg관리 auction player <이름> [return]` : 그 사람이 올린 물건 전부 삭제 (return 이면 돌려보냄)
  - `/rpg관리 auction clear confirm` : 옥션 물건 · 받지 않은 대금 · 물건 전부 삭제
  - 판매자가 접속 중이면 삭제 · 반환 사실을 알려 줍니다.

### 자동 적용 (config.yml `resourcepack`)
1. 기본값은 **내장 웹서버**로 배포합니다. `self-host.host` 를 서버 공인 IP/도메인으로 바꾸고 `port`(8765) 를 개방하세요.
2. 외부 호스팅(예: GitHub Release, mc-packs.net)을 쓰려면 `url` 과 `sha1` 을 입력하면 내장 웹서버는 꺼집니다.
3. 접속 1초 후 자동 전송, 적용 상태는 `/rpg관리 pack status` 로 확인합니다.
4. `required: true` 로 두면 거절 시 접속이 끊기고, 모두가 팩을 쓰므로 **GUI 배경이 자동으로 켜집니다** (`gui-overlay: auto`).
   선택 적용(`required: false`)에서는 팩이 없는 사람에게 네모 글자가 보이지 않도록 GUI 배경을 쓰지 않습니다.
5. 팩을 수정했다면 `plugins/RpgCraft/resourcepack.zip` 교체 → `/rpg관리 pack reload` → `/rpg관리 pack send all`

> 참고: 이 플러그인이 기존 아이템에 번호를 새로 붙였기 때문에(1.2.0), 이전 버전에서 이미 만들어진 일부 아이템(노말 검/도끼, 보스 세트, 사신수 무기 등)은
> 새 모델이 적용되지 않습니다. 테스트 서버라면 아이템을 새로 지급받는 것을 권장합니다. 기운(자연)의 재료가 거북 알 → 거북 비늘(SCUTE)로 바뀌었습니다.

## 빌드 (Java 21)

> 이 zip 은 **소스 프로젝트**입니다. 서버에 넣을 `RpgCraft.jar` 는 아래처럼 한 번 빌드해서 만듭니다.
> (jar 를 넣지 않으면 서버 `plugins` 폴더에 `RpgCraft` 폴더도 생기지 않습니다.)

### 가장 쉬운 방법
- Windows: `build.bat` 더블클릭
- macOS / Linux: `./build.sh`

→ `dist/RpgCraft.jar` 가 생성됩니다. 서버 `plugins` 폴더에 넣고 재시작하면 `plugins/RpgCraft/` (config.yml, bosses.yml, shops.yml, resourcepack.zip) 가 만들어집니다.

### 직접 빌드
```bash
mvn package                       # target/RpgCraft.jar
gradle build                      # build/libs/RpgCraft.jar  (Java 21 에서 실행하려면 Gradle 8.5 이상)
```
- 기본 설정은 **Java 21** 입니다. JDK 21 로 빌드하고, 서버도 Java 21 로 실행하세요.
- Java 17 서버용 jar 가 필요하면: `mvn package -Djava.release=17` / `gradle build -PjavaRelease=17` / `build.bat 17`
- 첫 빌드 때 인터넷에서 spigot-api 1.20.1 을 내려받습니다 (hub.spigotmc.org).

### 문제 해결
| 증상 | 원인 / 해결 |
|---|---|
| `Cannot find a Java installation matching languageVersion=17` | 예전 build.gradle 의 툴체인 설정 → 1.4.1 에서 제거됨 |
| `Unsupported class file major version 65` (Gradle) | Gradle 버전이 낮음 → Gradle 8.5 이상 사용 |
| `release version 21 not supported` | JDK 17 로 빌드함 → JDK 21 설치 (또는 17 옵션으로 빌드) |
| `UnsupportedClassVersionError` (서버 시작 시) | 서버가 Java 17 로 실행 중 → 서버를 Java 21 로 실행하거나 17 옵션으로 빌드 |
| `plugins/RpgCraft` 폴더가 없음 | jar 미설치 또는 로딩 실패 → 서버 콘솔에서 `RpgCraft` 로 시작하는 오류 확인 |

> 참고: 이 플러그인은 **Minecraft 1.20.1 (Spigot/Paper)** 용입니다. Java 21 이 필수인 1.20.5 이후(1.21 등) 서버는 API 이름이 바뀌어 별도 포팅이 필요합니다.

## 서버 세팅 순서 예시

1. 상점 NPC 배치: `/rpg관리 npc general`, `weapon`, `armor_warrior`, `special`, `wandering`, `war` ...
2. 보스 소환: `/rpg관리 boss spawn witch` (스케줄은 CommandScheduler 등 외부 플러그인 권장)
3. 성 만들기: `castle create north 북쪽성` → 성벽 영역 pos1/pos2 → `castle wall north 1 50000` ×3 → 신호기 설치 후 `castle beacon north`
4. 유적 만들기: `ruin create pyramid 피라미드` → 시작 블록 위에서 `ruin start pyramid` → 끝 블록 위에서 `ruin end pyramid` → `ruin first pyramid FC_PYRAMID`
5. 새 회차 시작: `/rpg관리 round next`
