# 02. 후대 시대 세계 설계 — 「베르사 새벽기」

> STEP 3 결과입니다. 원작의 사건은 **과거의 역사**이고, 플레이어는 그 뒤 오랜 시간이 흐른 세계에서 삽니다.
> 이 문서의 연표 · 세력 · 도시 · 몬스터 · 보스는 표시가 없으면 모두 `ORIGINAL` 입니다.
> 원작 지명은 이름만 이어받고, 모습은 **후대에 바뀐 모습**으로 다시 설계합니다.

## 1. 연표

| 시대 | 내용 | 분류 |
|---|---|---|
| 원작 시대 | 베르사 대륙의 왕국들이 싸우다 대륙 최초의 황제가 나와 통일 | CANON |
| 통일 제국기 (약 200년) | 대륙을 잇는 **황제의 길**(포장 도로망)과 역참이 깔림. 큰 전쟁이 없어 도시가 커짐 | ORIGINAL |
| 대분열 (약 40년) | 후계 다툼으로 제국이 갈라짐. 황제의 길 곳곳이 끊기고 국경 요새가 생김 | ORIGINAL |
| 잿빛 겨울 (약 10년) | 북부 빙원에서 시작된 이상 한파. 니플하임 옛 땅이 얼음에 덮이고 북부 인구가 남하 | ORIGINAL |
| 하늘이 떨어진 날 | 천공도시 라비아스(CANON)의 섬 하나가 무너져 중앙 대륙 호수에 떨어짐 → **추락 분화구** | ORIGINAL |
| 개척 시대 (현재, 개척력 37년) | 분열한 세력들이 교역으로 다시 이어지는 중. 서부 변경 개척, 옛 유적 재발견이 활발 | ORIGINAL |

플레이어는 **개척력 37년**에 들어온 새 모험가입니다. 원작 영웅들은 수백 년 전 **전설**이고, 그들의 이야기는 책 · 비석 · 노래 · 유적으로만 남아 있습니다.

## 2. 대륙 구조 (Minecraft 좌표)

- 월드 크기: 12,000 × 12,000 블록 (중심 0, 0). 걸어서 끝에서 끝까지 실제 시간 약 40분 이상.
- 대지 구조: 중앙 평원을 중심으로 북 · 남 · 동 · 서 네 지역 + 하늘 파편 · 지하 · 바다.
- 실제 영역 데이터: `src/main/resources/content/regions.yml` (플러그인이 읽는 진짜 데이터)

```text
                    [니플하임 빙원 폐허]  위험 5
                           │
     [토르 산맥 · 깊은 망치]──[모라타 자유시]──(북부 해안)
              │                   │
              │            ═══ 황제의 길(북로) ═══
              │                   │
[서부 변경]──[개척지 리스벨]──[하르덴 교역시]══[브렌트 고원 · 네할레스 성채]──[로자임 항만 연합]~~~(동쪽 바다 · 군도)
  위험 4~6    위험 2      │  (중앙)  │              위험 2                    위험 1
                     [세르벤 곡창]  [추락 분화구]  위험 4
                          │       (하늘 파편)
                    [칼라모르 폐도] 위험 3
                          │
                 ═══ 황제의 길(남로, 일부 끊김) ═══
                          │
          [공국 연맹 · 아스트라 학술도시] ── [모래바다 · 아질 오아시스]  위험 3~5
                                                 │
                                         [사구 아래 · 매몰 도시] 위험 5

   지하: [황제의 수로] — 하르덴 · 칼라모르 · 아스트라 아래를 잇는 옛 제국 지하망 (위험 3~6)
```

## 3. 위험도

| 단계 | 이름 | 예 |
|---|---|---|
| 0 | 안전 | 도시 안 |
| 1 | 평온 | 도시 근교 · 곡창 |
| 2 | 야생 | 고원 숲 · 개척지 주변 |
| 3 | 위험 | 폐도 · 사막 외곽 · 지하 수로 입구 |
| 4 | 고위험 | 추락 분화구 · 서부 깊은 숲 |
| 5 | 미지 | 니플하임 빙원 · 매몰 도시 |
| 6 | 최상위 | 서부 끝 「안개 장벽」 너머 · 수로 최심층 |

위험도에 따라 몬스터 · 자원 등급 · 사망 페널티 · 이벤트가 달라집니다 (`regions.yml` 의 `danger`).

## 4. 지역 — 존재 이유와 후대의 변화

각 지역은 02_WORLD 완성 기준(§33 질문)에 답하도록 설계했습니다.

### 하르덴 교역시 (중앙) — ORIGINAL
- **왜 여기?** 황제의 길 북로 · 남로 · 동로가 만나는 옛 역참이 시장이 되고 도시가 됨.
- **경제 역할:** 대륙 최대 시장 · 경매장 · 환전 · 상회 본부.
- **방문 이유:** 모든 재료가 모이는 곳. 단, 생산지보다 비싸다 (지역 시세 차이 → 교역).
- **후대의 흔적:** 도시 한가운데 옛 역참 건물이 박물관이 됨. 구시가지(제국기 석조) / 신시가지(목조 증축).

### 모라타 자유시 (북부) — 지명 CANON, 현재 모습 ORIGINAL
- **원작:** 북부의 작은 마을에서 시작해 왕국의 중심이 된 곳.
- **후대의 변화:** 잿빛 겨울 때 남하한 사람들을 받아들여 커졌고, 지금은 어느 나라에도 속하지 않은 **자유시**. 옛 광장의 조각상들은 대부분 풍화되어 **「풍화의 정원」** 이 됨.
- **경제 역할:** 장인과 예술가의 도시. 조각 · 재봉 · 염색 재료 거래.
- **방문 이유:** 생산 길드, 예술 · 조각 숙련 퀘스트, 북부 탐험 보급.

### 토르 산맥 · 깊은 망치 (북서) — 토르 CANON, 도시 ORIGINAL
- **원작:** 드워프 왕국, 대장장이 장인이 많은 곳.
- **후대의 변화:** 왕국은 「망치 맹약」 이라는 광산 도시 연합이 됨. 산 하나가 통째로 파여 **계단식 광산 도시**가 됨. 폐광은 몬스터 서식지.
- **경제 역할:** 금속 · 보석 생산, 대장 기술의 중심.
- **방문 이유:** 채광 · 대장 숙련, 고급 금속, 폐광 던전.

### 니플하임 빙원 폐허 (최북단) — 니플하임 CANON(역사), 현재 ORIGINAL
- **후대의 변화:** 잿빛 겨울로 얼음에 묻힌 옛 제국 도시. 얼음 속에 건물 꼭대기만 보인다.
- **왜 몬스터가 사나?** 얼음 속에서 깨어난 고대 생물, 추위에 적응한 짐승.
- **방문 이유:** 희귀 광물(서리 수정), 미지 지역 발견, 거대 보스.

### 브렌트 고원 · 네할레스 성채 (동부 내륙) — 지명 CANON, 현재 ORIGINAL
- **원작:** 로자임 북쪽 왕국, 수도 네할레스 성.
- **후대의 변화:** 왕국은 사라지고, 성은 **동로를 지키는 요새 겸 순례지**가 됨. 성 아래 고원 숲은 목재 산지.
- **경제 역할:** 목재 · 사냥 가죽. **방문 이유:** 벌목 · 사냥 · 성채 퀘스트.

### 로자임 항만 연합 (동부 해안) — 지명 CANON, 현재 ORIGINAL
- **후대의 변화:** 내륙 왕국이었던 로자임이 무역으로 바다 쪽 항구 도시들의 연합이 됨.
- **경제 역할:** 어업 · 해상 교역 · 조선. **방문 이유:** 낚시, 섬 · 난파선 탐험, 바다 보스.

### 세르벤 곡창 (중앙 남쪽) — ORIGINAL
- 넓은 평원(빈 공간 일부러 남김). 곡물 · 가축 → 요리 재료. 초보 사냥터.

### 칼라모르 폐도 (중앙 남쪽) — 칼라모르 CANON(역사), 현재 ORIGINAL
- **원작:** 하벤 제국에 멸망한 왕국.
- **후대의 변화:** 대분열 때 다시 전쟁터가 되어 완전히 폐허. 지금은 **유적 조사단**이 발굴 중. 지하로 황제의 수로가 이어짐.
- **방문 이유:** 역사 기록 발견, 고고학 퀘스트, 거대 보스 「무너진 파수거상」.

### 추락 분화구 (중앙 동쪽) — ORIGINAL (라비아스는 CANON)
- **왜 생겼나?** 하늘섬 파편이 떨어진 자리. 호수가 둥근 분화구 호수가 되었고, 가운데에 기울어진 하늘섬 조각이 꽂혀 있음 → **대륙 어디서나 보이는 랜드마크**.
- **방문 이유:** 하늘 금속 · 깃털 재료, 위험 4 지역, 보스 「파편 수호수」.

### 공국 연맹 · 아스트라 학술도시 (남부 경계) — 마법 공국 CANON, 도시 ORIGINAL
- **원작:** 남부와 중앙 사이 완충지대에 마법이 발달한 공국들.
- **후대의 변화:** 공국들이 연맹을 맺고 학술도시를 세움. 연금 · 마법 연구, 유적 연구자 집단의 본거지.
- **경제 역할:** 연금 · 시약 · 마법 재료.

### 모래바다 · 아질 오아시스 (남부) — 남부 사막 CANON, 도시 ORIGINAL
- **왜 여기?** 사막 한가운데 유일한 큰 샘. 대상단이 쉬어 가며 도시가 됨.
- **경제:** 소금 · 유리 · 향신료 · 사막 짐승 가죽. **위험:** 모래폭풍(월드 이벤트).
- **매몰 도시:** 사구 아래 옛 도시. 바람이 모래를 걷어 낼 때만 입구가 드러남(발견 콘텐츠).

### 서부 변경 · 개척지 리스벨 (서부) — 서부 지리 RESEARCH_REQUIRED → ORIGINAL
- **왜?** 서부는 원작 자료가 부족해 **완전히 새로 만든 미개척지**. 개척민 회의가 세운 목책 마을 리스벨이 문명의 끝.
- **방문 이유:** 지도에 없는 땅, 새 지역 첫 발견, 개척 퀘스트, 위험 4~6.
- **안개 장벽:** 서쪽 끝을 가리는 이상한 안개. 지금 버전에서는 넘을 수 없음(향후 확장).

### 황제의 수로 (지하) — ORIGINAL
- 통일 제국이 만든 지하 물길 · 창고 · 피난처. 대분열 때 버려져 몬스터 소굴이 됨.
- 하르덴 · 칼라모르 · 아스트라 아래를 잇는 **수직 탐험**: 지상 → 수로 입구 → 창고층 → 최심층.

### 동쪽 바다 · 군도 — ORIGINAL
- 로자임 앞바다 섬들, 난파선, 해저 유적. 해상 교역로와 해양 보스.

## 6. 교통

- **황제의 길**: 도시 사이 포장 도로. 길 위는 위험도가 한 단계 낮다.
- **역참 마차**: 이미 **발견한** 도시 사이만, 돈과 실제 이동 시간(수십 초 ~ 수 분)이 든다. 순간 이동이 아니다.
- **항로**: 로자임 ↔ 군도 ↔ 하르덴 운하.
- **미개척지 · 위험 지역**: 빠른 이동 없음.

## 9. 랜드마크
추락 분화구의 하늘섬 조각 · 깊은 망치의 계단식 산 · 하르덴 옛 역참 탑 · 네할레스 성채 · 니플하임 얼음 위로 솟은 첨탑 · 아질 오아시스 · 리스벨 목책과 안개 장벽.

## 10. 월드 제작 상태
- 지역 데이터(영역 · 위험도 · 자원 · 세력 · 이유)는 **코드가 쓰는 데이터 파일**로 만들었습니다.
- 실제 지형 · 건축물 제작은 아직 하지 않았습니다 → `EXTERNAL_ASSET_REQUIRED` (월드 제작 도구 · 건축 작업 필요). 03_FEATURE_REGISTRY 의 W-* 항목 참고.
